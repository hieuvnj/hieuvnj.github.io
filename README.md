# Trang Profile Cá Nhân (Personal Portfolio)

Trang web profile cá nhân tĩnh, hiện đại, hỗ trợ Dark/Light mode, hiệu ứng gõ chữ và chuẩn hiển thị trên mọi thiết bị (Responsive).

## Cấu trúc thư mục
- `index.html`: Cấu trúc nội dung (Thông tin cá nhân, Kỹ năng, Dự án, Liên hệ).
- `style.css`: Toàn bộ giao diện, hiệu ứng chuyển động, màu sắc.
- `script.js`: Hiệu ứng gõ chữ, chuyển đổi Dark/Light mode, thanh tiến trình cuộn trang.

## Cách xem thử trên máy tính (Preview)
Bạn chỉ cần mở trực tiếp file `index.html` bằng trình duyệt (Chrome, Brave, Firefox, Edge...) hoặc chạy một HTTP server đơn giản:
```bash
python3 -m http.server 8000
```
Sau đó truy cập: `http://localhost:8000`

## Cách triển khai lên mạng miễn phí (Deploy)
1. **Netlify Drop (30 giây):** Kéo thả thư mục `my-profile` vào trang [app.netlify.com/drop](https://app.netlify.com/drop).
2. **GitHub Pages (2 phút):** Đẩy mã nguồn lên repo GitHub `tên-bạn.github.io` để nhận link profile chuyên nghiệp.
